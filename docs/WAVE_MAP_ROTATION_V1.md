# 무한 생존 맵 순환 V1
사용자 제안: 보스 출현 웨이브마다 맵 변경. 5의 배수 웨이브 시작 전 교체하고 이후 일반 웨이브 4개까지 유지. 1~4 주엽공고 운동장, 5~9 학교 체육관, 10~14 노을빛 옥상, 15~19 네온 번화가, 20~24 정글 신전, 25~29 운동장, 반복. cycle[floor(wave/5)%5]. 보스 8명 무중복 랜덤 순환과 별개. 기존 스토리/PvP 변경 금지.
## 리소스
별도 전달 ZIP Juyeop_Wave_Maps_V1.zip: 1600x1000 PNG 5종, maps.json (경계/벽/스폰/맵순서), preview.html, README, layout_validation.txt. 이미지는 충돌 검증용 초기 아트이며 기존 고품질 정글 맵 대체 확정본 아님. 공개 브랜치에 PNG 미등록. 실제 엔진 월드 좌표/스케일 및 데이터 스키마 확인 후 변환. PNG에 구조물 합성되어 있으므로 중복 렌더링 금지. 최종 아트 변경 시 배치와 좌표 일치 재검증.
## 전환
이전 웨이브 보상·카드·회복 처리 완료 → 암전/로딩(시간·전투 정지) → 신규 지형+충돌+내비 데이터 동시 교체 → 안전 좌표 배치 → 맵명 및 보스 등장 연출 → 전투. HP/레벨/EXP/카드·진화/궁극기/포켓몬 편성/기록 유지. 이전 적·투사체·설치물·경로 제거. 소환수/쿨타임/지속효과는 기존 웨이브 정책 유지, 보상 중복 금지. 로드 실패 시 재시도 또는 안전한 이전 맵 진행.
## 설계/QA
6~8 벽, 중앙 넓게, 8개 스폰 후보. 안전 스폰 기준 초기 240거리 및 0.8초 예고, 후보 없음 지연. 벽은 일반 이동/직선탄 차단, 곡사 및 명시적 점프 예외 기존대로. 10px 정적 격자에서 반경24/48로 5맵 전 통과 가능 격자 연결 및 적8개/보스 스폰 접근 검증. 실제 이동/충돌/AI/성능 미검증. 실제 보스 반경, 거대화, 분신, 소환수, 벽 모서리, 대각선 충돌, 고속 이동, 경로 재탐색, 다수 적 성능 검증. 위험 지형은 V1 보류. 기존 흐릿한 구조물 복원은 별도 이슈.
맵 테마/규격/배치/순서는 사용자 위임에 따른 초기 선택이며 실제 플레이 후 조정.
