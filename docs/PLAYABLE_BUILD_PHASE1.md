# 1차 플레이 가능 빌드 범위
사용자 결정: 싱글/웨이브 모드 우선 완성, PvP 후속 개발. 기존 PvP 코드 및 PVP_TEAM_CONTROL_V1.md 보존. 모드 선택의 PvP 버튼은 준비 중(COMING SOON)으로 표시하고 진입 차단(제안 UI). 실제 온라인 매칭 및 팀전, PvP 봇 추가 개발, PvP 맵/MVP 리소스는 후순위.
## 우선순위
1. 싱글 스토리/영입 및 컷신, 저장 및 재접속 영입 유지. 미완성 미션은 준비 중 표시, 미구현 캐릭터 영입 경로 및 테스트 접근 별도 확인.
2. 웨이브 모드: 일반 60초, 5의 배수 보스, 맵 전환, 강화 카드, 캐릭터별 진화, 현곤 편성/진화/영입, 결과 및 최고 기록. 기존 무기/조작 유지.
3. 공통: 타이틀/모드 메뉴, HUD 및 스킬/카드 아이콘, 구조물 선명도 복원, 충돌 및 AI 우회, 모바일 길게 누르기 브라우저 기본 동작 차단.
4. QA: 8캐릭터 테스트 접근, 실제 기기 조작, 웨이브 전환/보스/카드/저장/재시작, 무한 발동 방지, 성능. 기존 타이틀 테스트 실패 별도 확인. PvP 회귀 최소 확인하되 신규 기능 제외.
## 완료 기준
싱글과 웨이브 각각 타이틀부터 결과/로비 복귀까지 중단 없이 진행 가능. 미완성 기능은 숨기거나 준비 중 명시. 빌드 테스트 결과와 잔여 결함 공유. main 변경 및 배포는 기존 협업 절차에 따름. 이 문서는 범위 결정이며 실제 빌드 변경 아님.
