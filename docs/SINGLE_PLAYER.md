# 싱글모드 진행 시스템

승인된 영입 컷신 프로토타입 3종을 우선 통합 대상으로 한다.

- 처음에는 시작 캐릭터만 해금. 시작 캐릭터는 미정.
- 현곤 보유 → 은숙 미션, 현곤+동기 보유 → 기섭 미션, 기섭 보유 → 상훈 미션.
- 각 미션의 세부 목표와 현곤/동기 획득 경로는 미정.
- 미션 성공 → 영입 컷신 → 영구 해금. 컷신 건너뛰기에도 해금 보장. 중복 보상 방지.
- 해금 캐릭터만 선택 가능. 잠금 캐릭터에는 선행 조건 표시.
- 진행도는 초기 HTML5 버전에서 버전이 있는 localStorage 저장 구조 제안. 기기/브라우저 간 자동 동기화는 별도 기능.
- 스토리 극장에서 완료한 영입 컷신 다시 보기. 다시 보기는 진행도 변경 없음.
- 기존 전투 테스트와 싱글 진행 상태 분리 권장.
- QA: 최초 실행, 선행 조건, 실패 시 미해금, 성공 및 스킵, 새로고침 후 유지, 재생 중 종료 복구, 중복 클리어, 모바일 가로 화면.
