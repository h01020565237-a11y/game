# 싱글 영입 난이도 및 플레이 시간 V1
사용자 결정: 싱글 미션 클리어로 영입하고 웨이브 해금, 영입 난이도를 조금 높여 플레이 시간 확보. 이하 수치/미션 상세는 초기 설계안으로 테스트 후 확정.
## 미션
|영입|선행/출전 조건|전투 목표|최초 성공 목표 시간|
|---|---|---|---|
|현곤|동기|기존 정글 일반 2단계 + 보스, 소환/지원 적 대응|3~5분|
|은숙|현곤|보호 대상 방어 + 보스|4~6분|
|기섭|동기+현곤|추격 및 돌진 회피, 보스 제한시간|5~7분|
|상훈|기섭|먹물/촉수 함정과 다수 적, 보스|5~7분|
|경수|상훈|분신 구별, 은신/기습 대응, 보스|6~8분|
|재한|추후 결정|연속 전투, 슈팅 회피|7~9분|
|정용|추후 결정|다단계 전투, 회복 저지/광폭화|8~10분|
선행 조건은 SINGLE_PLAYER_PHASE1 기준, 출전 제약의 정확한 의미는 기존 구현 확인. 기존 스토리 컷신 및 영입 순서 유지. 재한/정용은 기존 1차 영입 보류 상태이므로 신규 미션 구현 확정 전 준비 중 유지.
친구끼리 즐기는 게임이므로 반복 파밍이나 장시간 영입 요구를 피한다. 1차 5개 미션 성공 시간 총 23~33분, 전체 7개 완성 후 38~52분 목표. 재도전 포함 전체 약 60~90분은 검증 전 목표. 실제 플레이에서 과도한 길이/피로 시 단축. 체력·공격력 단순 인플레이션이나 반복 파밍 강제 대신 새로운 패턴, 목표, 조합으로 난이도 상승.
## 실패와 보상
실패 시 영입 없음, 무제한 재도전. 중간 단계 체크포인트 재도전 제안(해당 단계 진입 HP/강화 상태 복원, 보상 중복 금지). 보스 예고와 판정 일치, 회피 불가능 공격 금지. 모든 필수 미션은 해당 시점 영입 가능 캐릭터로 클리어 가능해야 함. 은숙 보호 대상 생존 조건, 기섭 제한시간 등은 실제 기기 테스트 후 수치 결정. 컷신 스킵 여부와 무관하게 승리 확정 시 영입 저장. 이미 영입한 캐릭터 재잠금 금지. 웨이브 모드 성장과 스토리 진행 분리. 
## QA
클리어 시간/시도 수/실패 구간/피해 원인/캐릭터별 성공률 기록. 초반 진입 장벽과 후반 공략 난이도 구분. 기존 미션 및 강화 선택/조작 유지. 실제 코드 및 main 변경 없음. Claude 통합 요청에 포함.
