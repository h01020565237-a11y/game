# 주엽공고 통합 전투 기획 V2
2026-11-25. 콘셉트 승인, 수치는 초기 테스트값. 기존 코드의 실제 상태는 별도 확인. main 변경 금지.

## 모드
스토리 미션 클리어 및 컷신으로 동료 영입. 기존 영입 순서/조건 유지. 무한 생존은 별도 모드이며 해금 캐릭터로 최고 웨이브/생존 기록 도전. 무한 생존 자체로 영입하지 않음. 적은 기존 스프라이트에 어두운 색과 보라 오라 적용, 아군 원본 불변. 웨이브 구성/난이도/보상은 추후 확정.

## 궁극기 충전
실제 적에게 입힌 피해 기반, 기본/일반 스킬/소환수/지속 피해 포함, 상자/피격/MISS/궁극기 자체 피해 제외(궁극기 소환수 및 분신 포함). 100% 발동 가능, 발동 즉시 0%. 은숙은 실제 아군 회복량도 일부 충전(계수 미정). 기준 피해5000, 초기 배율 동기100 현곤100 은숙140 기섭120 상훈100 경수110 재한100 정용120%. PvE/PvP 별도 설정. 과잉 피해 제외 권장. 충전 중 표시 및 완충 강조. 궁극기 발동 중 일반 공격 충전 허용 여부는 테스트 후 결정.

## 무한 생존 강화 카드 후보
런 종료 시 초기화, PvP/스토리 데이터 오염 금지. 카드 수치/중첩 상한/등장 규칙 미정.
- 동기: 카운터 강화, 콤보 확장.
- 현곤: 소환수 처치 시 회복, 적 공격력 감소, 소환 중 피해 감소, 궁극기 지속/소환수 공격속도 증가.
- 은숙: 슬로우 강화, 초과 회복 보호막, 회복 충격파, 궁극기 범위/지속 증가.
- 기섭: 하트 발사량+50%, 관통, 슬로우 강화, 지속 증가, 이동 잔상 피해, 처치 시 쿨타임 감소.
- 상훈: 삐짐 유지, 이동방해 저항, 피격 먹물 폭발, 촉수 수/범위, 먹물 미스+10%p/지속+2초/범위+30%.
- 경수: 후방 피해 증가, 은신 속도, 처치 시 은신 CD 감소, 분신 수 증가.
- 재한: 공 크기/피해, 강화 기본 공격 4→3회, 궁극기 3방향, 양발 감아차기/곡률 증가. 기존 벽 반사 강화는 E 변경으로 재검토.
- 정용: 피해 감소 강화, 꿀 회복 증가, 질주 추가 피해, 착지 범위 증가.

## 공통 UI
자신이 준 피해 초록, 자신이 받은 피해 빨강, 회복 파랑 +숫자, MISS/IMMUNE 회색, 치명타 크게. 피격 대상 위에 표시 후 상승/페이드. 모든 모드 동일. 소환수 피해 귀속 확인.
스킬/소환 버튼 길게 누르기 0.5초 초기값으로 설명 표시, 단순 확인 후 손 떼면 발동 금지, 드래그 조준 시 닫고 기존 조작 유지. PC hover. 실제 스킬 데이터와 설명 연동. 이미 구현된 부분은 중복 작업하지 않음.

## QA 및 구현 순서
기존 기능/Claude 최신 작업 먼저 확인. 데이터 및 궁극기 공통 시스템 → 캐릭터별 스킬 → 생존 모드/카드. 기존 스토리 영입/저장/컷신/배틀로얄 회귀 검증. 궁극기 무한 충전 방지, 피해/회복 귀속, 소환 종료 정리, 은신/분신 AI, 벽 충돌, 모바일 터치 취소 및 PC 키 충돌 검증. 동일 조건에서 8명 웨이브 도달/보스 처치 시간/생존/궁극기 빈도 비교, 지원형 및 기동형도 충분히 경쟁력 확보. 무한 모드는 최종 클리어가 아니라 기록 도전. 확정되지 않은 수치는 설정 데이터로 분리하고 임의 확정하지 말 것.
