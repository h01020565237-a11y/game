# 주엽공고 영입 컷신 리소스

승인된 5편 원본 및 분리된 30장 WebP, 타임라인 JSON, 테스트용 오리지널 합성 효과음/BGM WAV, 로컬 HTML 미리보기. 압축 해제 후 preview.html 열기. 실제 게임 엔진 통합은 미완료.

## Claude 적용
- timeline.json stories의 배열 순서가 실제 재생 순서. duration/voice/sfx는 초 단위, motion은 연출 힌트. 원본 번호/타임코드가 이미지에 포함되어 있으므로 실제 게임에서는 해당 영역만 UI로 가리거나 승인된 장면을 그대로 표시. 원본 말풍선 중복 자막 피하기. 화면 비율 제각각이므로 contain으로 잘림 방지, 나머지 영역은 어두운 배경/블러 처리. 확대시 말풍선 잘리지 않게.
- 상훈: 사용자가 불필요하다고 한 차 안 무대사 컷 제외. 자동차 다리 → 상훈 대사 → 기섭 비웃으며 대사 → 섬 → 영입 성공. 승인 원본은 originals에 보존.
- 은숙: 새벽별교회 표기 유지, 교회 사람의 대답과 마지막 반응/영입 화면 분리.
- 기섭: 집 안, 동기 혼자 앉음, 취한 현곤이 혼자 매트리스 끌기, 동기 ㅋㅋㅋ, 현곤 웃음, 기섭 웃기냐? 이후 동기 당황/현곤 계속 웃음/기섭 무대사 씩씩. 흰 찢어진 러닝 및 배 나온 외형 유지.
- 경수: 상훈 사각 안경, 경수 동그란 안경/더 큰 키, 대사 없음. 실제 사진 삽입 없음.
- 이미지에 새 디자인 생성이나 재구성하지 말 것.
- 음성: 실제 음성 파일은 미포함. 브라우저 Web Speech API ko-KR 목소리로 임시 재생. pitch/rate만으로 정확한 성별/음색/감정 구현 보장 안 됨. 음성 선택 가능 시 역할에 맞게 선택하고 최종 음성은 별도 녹음/TTS 제작. 음성 미지원 환경에서도 컷신 정상 종료. 웃음 TTS 품질 한계 있음. 효과음은 합성 테스트용이며 실제 웃음/환경음 녹음 아님. 경수 편 웃음은 별도 녹음 효과음 추가 권장.
- preview.html은 독립 미리보기, 게임 영입/저장 연동 없음. 실제 구현 시 스킵/종료 시 예약 타이머와 음성/SFX/BGM 종료, 최초 영입 저장 유지, 극장 중복 영입 금지. 기존 볼륨 설정에 voice/BGM/SFX 연결. 장면별 이미지 사전 로드.
- 영입 성공 화면 3초 기본값, 일부 원본 표시 시간과 다른 새 타임라인은 연출용 초안. 사용자에게 받은 외형/대사 우선. 기존 main 및 전투 변경 금지.
