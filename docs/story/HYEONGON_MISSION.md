# 현곤 영입 미션
- 플레이어: 동기
- 맵: 기존 정글
- 적: 쉬운 AI 3명
- 성공: 최후의 생존자
- 실패: 재도전 가능, 횟수 제한 없음
- 초반 이동, 공격, 상자 파괴, 무기 획득, 스킬 조작 안내. 안내는 전투를 방해하지 않도록 구성.
- 성공 후 대화역 컷신: 동기 '대화역은 이쪽이지!' / 수풀에서 현곤 등장 '대화역은 저쪽이지! 너 맞을래?' / 화면 정지 및 현곤 영입 완료.
- 컷신 스킵 시에도 영입 지급, 중복 지급 방지, localStorage 저장, 스토리 극장 다시보기.
- 실패 시 영입하지 않음. 기존 전투 시스템 유지. main 변경 없이 테스트 브랜치에서 구현 및 검수.
