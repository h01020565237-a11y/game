# 영입 영상 연출 V2
승인된 5개 에피소드의 연출 기준. 기존 영입 조건, 저장, 스킵, 극장 재생 유지. 재한/정용 보류. 기존 3D 치비 캐릭터 원본 사용, 참고 이미지로 외형 변경 금지. 실제 사건의 핵심 대사 유지. 추가 연출은 코미디용.

## 현곤 — 대화역 사건 (18초)
0–4초 동기가 평화로운 거리를 걸으며 방향을 가리킴: “대화역은 이쪽이지!”
4–7초 수풀 흔들림, 부스럭 효과음, 동기 고개 돌림, BGM 정지.
7–11초 현곤 수풀에서 등장, 반대 방향 가리킴: “대화역은 저쪽이지!”
11–14초 1초 정적, 얼굴 급확대/집중선/쾅: “너 맞을래?!”
14–16초 동기 황당한 표정, 눈 깜빡임, 무대사.
16–18초 영입 성공: 현곤 / 평화주의 소환사.

## 은숙 — 현곤 오빠의 행방 (22초)
0–5초 현곤이 교회 전단지 전달: “우리 교회 놀러 와!” 은숙 “네, 오빠!”
5–9초 며칠 후 은숙 교회 도착, 전단지 소지, 경쾌한 BGM.
9–13초 은숙 “현곤 오빠 어딨어요?” 교회 사람 “현곤이?” 정적/BGM 정지, “걔 군대 갔어.”
13–17초 군부대 컷, 짧은 머리/군복 현곤 행군, “하나! 둘! 하나! 둘!”
17–20초 교회 복귀, 은숙 전단지 내려다봄, 무대사, 회색 화면 전환.
20–22초 영입 성공: 은숙 / 든든한 수호자.

## 기섭 — 매트리스 사건 (18초)
0–4초 방에서 현곤이 침대 매트리스를 끌어당기며 낄낄 웃음.
4–8초 옆 동기도 웃음, 둘이 서로 보고 크게 웃음.
8–11초 BGM 정지, 뒤로 거대한 그림자, 카메라 위로 이동해 기섭 얼굴 공개.
11–14초 기섭 낮고 진지하게 “웃기냐?” 둘의 웃음 즉시 멈추고 얼어붙음. 추가 대사 없음.
14–18초 영입 성공: 기섭 / 자기애의 질주자.

## 상훈 — 바다에 떠 있는 땅 (18초)
0–4초 바다 위 다리를 달리는 자동차, 기섭과 상훈, 경쾌한 여행 BGM.
4–8초 상훈 창밖 가리키며 “어! 저기 바다에 땅이 떠 있다!” 평범한 섬 컷.
8–12초 BGM 정지, 약 1초 정적, 기섭 황당한 표정 “저게 섬이라는 거야!!”
12–15초 섬 확대, 화살표와 “섬” 자막, 띵동 효과음.
15–18초 영입 성공: 상훈 / 삐진 쭈꾸미. 이야기 중 평상복, 영입 화면 쭈꾸미 복장. 운전자 신원은 미정이므로 운전석에서 고개 돌리는 위험한 연출 불필요.

## 경수 — 운명의 커플룩 (약 20초 + 영입 화면)
0–4초 밤 번화가, 상훈 줄무늬 티셔츠/어두운 바지 차림.
4–8초 반대편 경수 동일한 상하의.
8–11초 서로 발견, 멈춤, BGM 정지.
11–14초 상의/바지 교차 확대.
14–17초 서로 얼굴 보며 동시에 웃음.
17–20초 나란히 걷는 뒷모습, 셔터 효과, 정지 화면. 실제 사진 구도 참고, 원본 사진 사용은 파일 확보 및 별도 확인 후.
이후 영입 성공: 경수 / 뒤끝 있는 암살자. 대사 없음. 상훈 쭈꾸미 복장 금지(이야기 장면).

## 제작 및 QA
공통 영입 화면: 남색 배경, 금색 NEW CHARACTER UNLOCKED, 기존 전신 이미지, 이름/칭호, 새로운 동료를 영입했습니다. 자막은 이미지에 굽지 않고 UI 텍스트 권장. 장면별 배경/캐릭터 포즈/표정/카메라/효과음 분리. 16:9 중심 안전 영역, 모바일/PC 대응. 스킵 가능, 스킵해도 최초 영입 저장 유지, 극장 재생 시 중복 보상 없음. 기존 구현과 비교 후 수정, main 변경 금지. 영상 파일 및 신규 장면 리소스는 아직 미제작. 실제 구현 매체(게임 내 타임라인 또는 영상 파일)는 기존 시스템과 리소스 확인 후 결정.
