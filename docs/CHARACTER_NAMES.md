# Battle Lab 캐릭터 이름 확정

| 기존 ID | 표시 이름 | 외형 |
|---|---|---|
| stripe | 경수 | 흑백 줄무늬 티셔츠 |
| soccer | 재한 | 국가대표 팀 유니폼 |
| support | 은숙 | 여성 정장 |
| summoner | 현곤 | 포켓몬 트레이너 |
| suit | 동기 | 안경 쓴 정장 남성 |
| octo | 상훈 | 쭈꾸미 인형탈 |
| bear | 정용 | 곰 인형탈 |
| runner | 기섭 | 머리띠, 흰색 런닝 |

기존 내부 ID, 외형, 스킬, 능력치 및 에셋 경로는 유지. 표시 이름만 캐릭터 선택, 전투 HUD, 결과 화면 등에 일관되게 적용. 실제 코드 적용은 추후 통합 시 진행.
