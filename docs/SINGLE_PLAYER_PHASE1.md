# 싱글모드 1차 완성 범위

동기 기본 지급. 현곤(동기), 은숙(현곤), 기섭(현곤+동기), 상훈(기섭), 경수(상훈) 영입. 재한과 정용은 싱글 영입 보류, 전투 테스트에서는 사용 가능.

## 경수: 뜻밖의 커플룩
밤 번화가에서 상훈과 경수가 따로 걸어오다가 마주친다. 상하의가 같다는 사실을 발견한다. 대사 없이 옷 확대, 정적, 당황한 표정, 코믹 효과음, 나란히 걸어가는 뒷모습으로 연출. 상훈은 문어 탈 대신 줄무늬 상의와 바지를 착용. 약 15~20초. 실제 사진은 구도 참고용이며 게임 삽입은 필수가 아니다. 표정과 행동은 각색이다. 마지막 경수 영입 완료 표시.

## 구현 기준
기존 스토리 4종과 경수 스토리를 영입 시스템에 연결. 영입 조건 충족 후 미션 진입, 성공 시 컷신과 영입 완료. 미션별 클리어 조건은 아직 미확정이며 데이터로 분리. 컷신 스킵 가능, 스킵해도 영입 지급. 중복 지급 방지, 새로고침 후 진행 유지(localStorage), 영입 완료 스토리 극장 재생. 잠긴 캐릭터는 조건 표시, 재한·정용은 준비 중 표시. 메인 로비 중앙 전신 이미지 없음. 기존 전투 로직 유지. Claude 통합 후 테스트 브랜치에서 검증, main 변경 금지.
