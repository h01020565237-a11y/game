# 싱글 영입과 웨이브 캐릭터 해금
사용자 확정: 싱글 모드에서 영입 완료한 캐릭터만 웨이브 모드에서 선택 및 플레이 가능. 동기는 최초 기본 해금, 나머지 7명은 초기 잠금. 웨이브 모드 자체는 최초부터 진입 가능.
- 기존 싱글 영입 저장 데이터를 단일 기준으로 사용. 미션 클리어 확정 시 영입 저장, 컷신 스킵/재생 여부와 무관. 재접속 후 유지.
- 웨이브 선택 화면에 잠긴 캐릭터는 회색/자물쇠, 영입 조건 및 해당 싱글 미션 안내. 미구현 영입 미션은 준비 중 명시. 미영입 캐릭터 전투 시작 차단(선택 UI뿐 아니라 시작 검증).
- 웨이브 내 강화, 진화, 포켓몬 영입은 해당 런 한정이며 싱글 캐릭터 영입과 별개. 웨이브 기록 초기화가 영입 해금을 삭제하지 않도록 분리.
- QA 전용 전체 해금은 일반 사용자 저장과 분리하고 테스트 빌드에만 허용하는 방안 제안.
- QA: 신규 저장 동기만, 영입 전 잠금, 승리 및 컷신 스킵 직후 해금, 패배 시 잠금, 재접속 유지, 미션 재클리어 중복 방지, 손상 저장 안전 처리, 웨이브 재시작 및 런 초기화 시 해금 유지.
- PLAYABLE_BUILD_PHASE1.md와 함께 적용. PvP 해금 규칙은 후속 결정. 기존 main 및 게임 코드 변경 없음.
