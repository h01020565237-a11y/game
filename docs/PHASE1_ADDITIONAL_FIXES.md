# 추가 수정 요청
## BUG-05 현곤 소환 버튼 이미지
실제 소환수 크기가 아닌 인게임 소환 스킬 버튼 내부 포켓몬 이미지 크기 문제. 버튼 내부 이미지 최대 지름 75% 초기안, 원본 비율 유지, 중앙 정렬, 영역 넘침 방지, pointer-events:none 등으로 이미지가 입력 가로채지 않도록 처리. 일반/진화/전설 동일. 기존 조준, 쿨타임, 입력 영역, 실제 소환수 크기 유지. 모바일 화면별 검증. 1차 빌드에 반영.
## BUG-06 PvP 보물상자
사용자 확정: 파괴 후 사라지고 일정 시간 후 재생성. 짧은 파괴 연출, 기존 아이템 드롭 1회, 즉시 충돌/타겟 제거. 20초 후 기존 위치 재생성은 초기 제안값, 데이터화. 캐릭터가 겹치면 비울 때까지 지연. 재생성 시 HP/충돌/타겟 복구, 짧은 등장 연출. 중복 타이머 및 드롭 방지, 경기 종료/맵 변경 시 취소. 기존 PvP 개발은 후순위이므로 1차 빌드 일정 지연 없이 후속 적용, 공통 상자 로직을 변경할 경우 싱글/웨이브 의도치 않은 재생성 방지. 실제 구현 전 기획 기록.
