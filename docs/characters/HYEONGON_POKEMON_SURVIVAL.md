# 현곤 무한 생존 포켓몬 성장
승인된 방향: 무한 생존에서만 포켓몬 진화 및 전설/환상 영입. 기본 8종에서 3마리 선택, 웨이브 사이 보유 목록에서 3슬롯 교체, 진화는 동일 슬롯 교체, 신규 영입은 보유 목록 추가, 런 종료 시 초기화. 스토리/BR 변경 금지. 기존 1마리 소환/궁극기 3마리 유지. 지속 소환은 제안 단계이므로 아직 변경하지 않음.
일반 카드: 소환수 체력/공격력/공격속도. 희귀: 보유한 진화 가능 포켓몬 1단계 진화. 전설: 신규 전설/환상 영입. 일반 웨이브 낮은 확률, 보스 보상 높은 확률. 중복 영입/최종 진화 카드 제외. 진화 초기 제안 HP/ATK +30%, 특수 효과 +20%, 사거리 +15% (밸런스 미확정).
진화: 25→26, 4→5→6, 7→8→9, 1→2→3, 92→93→94, 39→40. 잠만보/라프라스는 진화 대신 전용 강화.
추가 포켓몬 초기 역할: 레시라무 광역 화염/지속피해, 뮤 회복/무작위 특수 공격, 뮤츠 사이코키네시스, 레쿠쟈 직선 관통, 루기아 폭풍/넉백, 제크로무 전기/기절. 수치/AI 미확정.

## 이미지
AI 재생성 금지.
