# 무한 생존 전용 강화 카드 및 스킬 진화
기존 CHARACTER_COMBAT_V2, ENDLESS_SURVIVAL_V1, HYEONGON_POKEMON_SURVIVAL 기획을 확장. 스토리/BR에는 적용 금지. 수치와 해금 조건은 초기 제안이며 QA 후 확정.

## 공통 성장 원칙
회복/회피/이동/제어 스킬의 기존 효과를 유지하면서 강화 및 진화 시 공격 능력 추가. 모든 캐릭터가 솔로 PvE에서 성장 가능해야 함. 동일 충격파 반복 대신 투사체, 설치물, 지속 피해, 반사, 소환 등 고유 테마 유지.
기본→강화→진화. 초기 제안: 해당 스킬 강화 카드 누적 3회 이후 전설 진화 카드 후보에 추가, 스킬별 1회. 금색 아이콘 테두리/이펙트 표시. 진화와 단순 능력치 카드는 구분. 현곤 포켓몬 개별 진화는 기존 희귀 카드 규칙 유지, 스킬 진화 조건으로 제한하지 않음.

- 현곤: 소환수 HP+20%, 공격력+15%, 공격속도 강화 / 포켓몬 진화, 소환 지속+30% / 전설·환상 영입, 평상시 최대 2마리, 궁극기 지속+4초. 소환 스킬 진화: 등장 즉시 해당 포켓몬 고유 특수 공격. 기존 소환 제한 변경은 전설 카드 효과에 한정.
